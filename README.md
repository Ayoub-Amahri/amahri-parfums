# AMAHRI PARFUMS 🌟

### E-commerce Website | React Frontend Project

**AMAHRI PARFUMS** est un projet personnel de site e-commerce dédié à la présentation et à la vente de parfums inspirés de différentes fragrances.

Ce projet a évolué progressivement, d'une première version développée avec HTML, CSS et JavaScript vers une application React moderne, structurée autour de composants réutilisables.

🌐 **[Voir le site en ligne](https://amahri-parfums.netlify.app/)**

## 🚀 Évolution du projet

### V1 — Première version
- Création du site avec HTML5, CSS3 et JavaScript.
- Développement des premières pages et fonctionnalités e-commerce.
- Mise en place du catalogue de parfums.

### V2 — Amélioration UI/UX
- Refonte du design et de l'interface utilisateur.
- Amélioration de la navigation.
- Optimisation du catalogue, du panier et des favoris.
- Adaptation de l'interface aux différents écrans.

### V3 — Migration vers React (version actuelle)
- Migration de l'application vers React et Vite.
- Organisation du code en composants réutilisables.
- Gestion de la navigation avec React Router.
- Gestion de l'état partagé avec Context API.
- Conservation du panier et des favoris avec localStorage.
- Déploiement de la nouvelle version sur Netlify.

## 🛠️ Technologies utilisées

- **React** — Développement de l'interface utilisateur.
- **Vite** — Outil de développement et de build.
- **JavaScript (ES6+)** — Logique et interactions.
- **HTML5 / CSS3** — Structure et mise en forme.
- **React Router** — Navigation entre les pages.
- **Context API** — Gestion d'état partagé.
- **localStorage** — Persistance des données côté navigateur.
- **Git & GitHub** — Versionnement du code.
- **Netlify** — Hébergement et déploiement.

## ✨ Fonctionnalités

- Catalogue de parfums Homme et Femme.
- Recherche et filtrage des produits.
- Fiches produits avec choix du format (30 ml / 50 ml).
- Panier avec gestion des quantités.
- Liste de favoris (Wishlist).
- Conservation du panier et des favoris après actualisation.
- Préparation des commandes via WhatsApp.
- Interface responsive pour Mobile, Tablette et Desktop.

## 💻 Installation locale

**1. Cloner le repository**

`git clone https://github.com/Ayoub-Amahri/amahri-parfums.git`

**2. Accéder au projet React**

`cd amahri-parfums/amahri-website`

**3. Installer les dépendances**

`npm install`

**4. Lancer le serveur de développement**

`npm run dev`

Ouvrir ensuite l'adresse locale indiquée par Vite dans le terminal.

**5. Générer une version de production (optionnel)**

`npm run build`
