# AMAHRI PARFUMS

### E-commerce Website | Frontend Project

AMAHRI PARFUMS est un projet personnel de site e-commerce dédié à la vente de parfums inspirés de différentes fragrances.

J'ai développé ce projet avec HTML, CSS et JavaScript, puis réalisé une deuxième version (V2) pour améliorer le design, la navigation et l'expérience utilisateur.

## 🌐 Live Demo

[Voir le site web](https://amahri-parfums.netlify.app/)

## 🛠 Technologies utilisées

- HTML5
- CSS3
- JavaScript
- Git & GitHub
- Netlify

## ✨ Fonctionnalités

- Catalogue de parfums Homme et Femme
- Recherche et filtrage des produits
- Fiches produits avec choix du format (30 ml / 50 ml)
- Panier avec gestion des quantités
- Liste de favoris (Wishlist)
- Préparation des commandes via WhatsApp
- Design responsive (Mobile, Tablette et Desktop)

## 🚀 Améliorations de la V2

- Refonte de l'interface UI/UX
- Nouveau design moderne et élégant
- Amélioration de la navigation
- Réorganisation du catalogue
- Amélioration du panier et des favoris
- Optimisation de l'affichage sur mobile

## 💻 Installation locale

1. Cloner le repository :

`git clone https://github.com/Ayoub-Amahri/amahri-parfums.git`

2. Ouvrir le dossier `amahri-website` dans VS Code.
3. Lancer `index.html` avec Live Server.
